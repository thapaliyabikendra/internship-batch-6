# .NET Intern Skills Test

This repository contains a 1-hour skills test for .NET internship candidates.

## Test Structure

The test is divided into six sections:

1. **Core Concepts** (15 minutes) - Testing fundamental C# and .NET knowledge
2. **ASP.NET Core API** (15 minutes) - Creating a simple HTTP endpoint
3. **Entity Framework & LINQ** (10 minutes) - Data access patterns
4. **SQL** (5 minutes) - Basic queries and understanding
5. **Debugging** (10 minutes) - Fixing errors in code
6. **Problem-Solving** (5 minutes) - Implementing a simple algorithm

## Files

- `dotnet-test.md` - The test questions
- `dotnet-test-solutions.md` - Example solutions (for evaluators only)

## Instructions for Candidates

1. You have 1 hour to complete the test
2. Create a new file with your answers named `[your-name]-answers.md`
3. Commit your answers to this repository in a new branch named `[your-name]-test`
4. Create a pull request when finished

## Evaluation Criteria

Candidates will be evaluated on:
- Correctness of answers
- Code quality and style
- Problem-solving approach
- Understanding of .NET concepts
- Ability to explain solutions clearly

Good luck!
